# Charade visual lessons

Open [the gallery](index.html) in a browser. Use the left and right arrow keys to move between lessons. Click a diagram to open it full-size. Each lesson includes downloadable SVG and PNG images and a text explanation.

The diagrams were authored with Codex. Numerical examples are illustrative, not measured Charade results. No production implementation or trained model was changed.
