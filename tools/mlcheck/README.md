# mlcheck

Release gates for ML systems: data contract, leakage, reproducibility, recomputed model quality with block-bootstrap CIs, calibration, train/serve and ONNX parity, latency, ranking-policy invariants, drift.

`uv run mlcheck <project> [--stage …] [--only CODE] [--format json] [--strict] [--list]`

Full documentation, artifact contract and the check catalogue: [docs/mlcheck.md](../../docs/mlcheck.md).
